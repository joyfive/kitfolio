# 검색어 정렬 작업 (2026-11-18)

AdSense "가치가 별로 없는 콘텐츠" 4차 대응. 콘텐츠 고유성은 이미 갖췄다고 보고,
**사람들이 실제로 치는 검색어와 페이지 표기(title·description·keywords·FAQ)의 어긋남**을 맞춘다.

## 기준선 (2026-11-09, Search Console)

| 항목 | 값 |
|---|---|
| 색인 생성됨 | 60 |
| 색인 안 됨 | 85 (발견됨-미색인 58 · 리디렉션 10 · 대체 페이지 7 · noindex 6 · 크롤링됨-미색인 4) |
| 최근 3개월 실적 | 클릭 1 · 노출 67 · CTR 1.5% · 평균 순위 23.5 |

30일 이상 지난 뒤 같은 화면을 같은 기간 설정으로 다시 캡처해 비교한다.
측정 기간 동안 새 페이지 추가 · URL 변경 · 병합은 하지 않는다.

## 원칙

- 페이지당 핵심 검색어 1개를 title 앞에 둔다. 사람들이 붙여 쓰는 표기(글자수 · QR코드 · 그라데이션)를 그대로 쓴다.
- h1(`name`)과 허브 카드 이름은 바꾸지 않는다. 검색 결과에 보이는 title 만 검색어 쪽으로 옮긴다.
- 키워드를 본문에 끼워 넣지 않는다. 질문형 검색어는 FAQ 질문 문장으로만 받는다.
- 이번 범위는 KO 만. EN 은 손대지 않았다.

## 바꾸지 않은 도구

- 웹 접근성 5종 · OG 미리보기 · 퇴직금 · 광고 예산 페이싱 · 퍼널 전환율 · KST UTC · 슬랙 메시지 빌더:
  title 이 이미 핵심 검색어로 시작한다.
- 연차 · 프리랜서 3.3% · 종합소득세 · 부가세 · 실업급여: title 은 이미 검색어형이다.
  이 5종의 과제는 검색어가 아니라 `indexable: false` 승격 판단(법령 원문 대조)이다.

## 확인하지 못한 것

- **검색량.** 새 키워드는 표기 관습 기준의 추정이다. 네이버 검색광고 키워드 도구에서
  title 앞에 둔 핵심 검색어(위 표 "새 title" 의 첫 구간)의 월간 검색량을 확인하고,
  검색량이 거의 없는 표기면 되돌린다.
- **미색인 58개의 URL 구성.** KO/EN 비율과 어떤 도구인지 모른다. Search Console 에서
  "발견됨 - 현재 색인이 생성되지 않음" URL 을 내보내 이 문서에 붙인다.

## 배포 후 할 일

1. 배포 확인 후 Search Console 에 sitemap 재제출.
2. URL 검사 → 색인 생성 요청: 하루 할당량이 있으니 위 변경 목록 순서대로 KO URL 부터 나눠서 요청.
3. 30일 뒤(2026-12-18 이후) 기준선과 같은 항목으로 비교.
