# 기획서: 프리랜서 3.3% 계산기 (2026-10-01 초안)

## 1. 한 줄 정의

**프리랜서 3.3% 계산기는 외주비·강연료·원고료 지급액에서 원천징수되는 소득세와
지방소득세를 빼고 실수령액을 계산하고, 원하는 실수령액에 맞는 계약 금액을 역산하는 도구다.**

## 2. 검색 의도와 사용자

| 항목 | 내용 |
|---|---|
| 주 검색 의도 | "3.3% 계산기" · "프리랜서 세금 계산" (지급액을 넣으면 실수령액이 얼마인가) |
| 보조 의도 | "3.3 역산" (실수령 N원 받으려면 계약서에 얼마를 써야 하나) · "8.8% 계산기" (강연료·원고료) |
| 사용자 | 외주 디자이너·개발자·PM, 강연·기고하는 직장인, 프리랜서에게 돈을 지급하는 담당자 |
| 반복 상황 | 견적서 작성, 계약 금액 협상, 입금액 확인, 지급 담당자의 원천징수액 계산 |
| 타겟 태그 | `designer` · `developer` · `pm` · `office-worker` |

담당자(지급하는 쪽)도 같은 계산을 한다. 결과 카드 문구는 "받는 사람"과 "주는 사람" 어느 쪽이 읽어도 맞게 쓴다.

## 3. 산식

### 3.1 사업소득 3.3% (기본 탭)

```
소득세       = 지급액 × 3%                → 10원 미만 절사
지방소득세   = 소득세 × 10%               → 10원 미만 절사
원천징수세액 = 소득세 + 지방소득세
실수령액     = 지급액 − 원천징수세액
```

- 근거: 소득세법 제129조 제1항 제3호 (사업소득 원천징수세율 3%),
  지방세법 제103조의13 제1항 (소득세의 10% 특별징수)
- 지방소득세는 **절사된 소득세**에 10%를 곱한다.

### 3.2 기타소득 8.8% (두 번째 탭)

```
필요경비     = 지급액 × 60%   (강연료·원고료 등 인적용역 일시 소득의 필요경비 의제)
기타소득금액 = 지급액 − 필요경비
소득세       = 기타소득금액 × 20%   → 10원 미만 절사
지방소득세   = 소득세 × 10%        → 10원 미만 절사
```

- 근거: 소득세법 제21조 제1항 제15호·제19호 · 제37조 · 시행령 제87조 (필요경비 60%),
  제129조 제1항 제6호 (기타소득 원천징수세율 20%)
- **과세최저한**: 건별 기타소득금액 5만 원 이하면 과세하지 않는다 (소득세법 제84조).
  필요경비 60% 기준으로 **지급액 125,000원 이하면 세금 0원.**
- 연간 기타소득금액 300만 원 이하는 분리과세를 선택할 수 있다는 안내를 가이드에 넣는다 (계산에는 반영하지 않음).

**소액부징수 결론.** 일반적인 3.3% 프리랜서(면세 인적용역을 계속·반복 공급)는 시행령 제149조의3 에
해당하므로 소득세가 1,000원 미만이어도 원천징수한다. 계산기는 다음처럼 처리한다.

- 사업소득 탭: 소액부징수를 **적용하지 않는다.** 소득세가 1,000원 미만인 금액에서는
  "이 예외에 해당하지 않는 사업소득은 징수하지 않을 수 있다"는 안내를 붙인다.
- 기타소득 탭: 1,000원 미만이면 0원으로 계산한다. 다만 과세최저한(지급액 125,002원 이하면 0원,
  기타소득금액 1원 미만 버림 반영)이 먼저 걸리므로 실제로 이 규칙이 작동하는 금액은 없다.
- 참고: 시행령 제137조는 법 제73조 제1항 제4호(과세표준확정신고의 예외) 위임 조문이라 이 도구와 무관하다.

### 3.4 역산 (차별화 핵심)

실수령액 N원을 받으려면 지급액을 얼마로 해야 하는지 계산한다.

- 단순 나눗셈(N ÷ 0.967)은 절사 때문에 정확한 답이 아니다.
- 구현: 근사값 `ceil(N ÷ (1 − 실효율))` 근처에서 **실수령액 ≥ N 을 만족하는 최소 지급액**을 탐색한다.
  절사 단위가 10원이므로 근사값 ± 수십 원 범위만 보면 된다.
- 정확히 N원이 되는 지급액이 없으면 "N원 이상이 되는 최소 금액"과 그때의 실수령액을 함께 보여준다.
- 소액부징수·과세최저한 경계에서는 결과가 불연속이다. 경계 바로 아래 금액이 더 유리할 수 있다는 점을 결과에 표시한다.

**검산 예시 (사업소득)**

| 실수령 목표 | 단순 나눗셈 | 정확한 최소 지급액 | 그때 실수령액 |
|---|---|---|---|
| 3,000,000 | 3,102,379 (실수령 3,000,009) | **3,102,370** | 3,000,000 |

```
3,102,370 × 3% = 93,071.1 → 93,070
93,070 × 10%   = 9,307    → 9,300
3,102,370 − 102,370 = 3,000,000
```

## 4. 화면 구성 (Layout A · Card)

```
┌ 인풋 카드 ──────────────────────┐   ┌ 결과 카드 ──────────────────────┐
│ [사업소득 3.3%] [기타소득 8.8%]  │   │ 실수령액  967,000원  ← primary   │
│ ( ) 지급액 → 실수령액           │   │ 소득세        30,000원           │
│ ( ) 실수령액 → 지급액 (역산)     │   │ 지방소득세     3,000원           │
│ 금액 [ 1,000,000 ] 원           │   │ 원천징수 합계 33,000원 (3.3%)    │
│ 빠른 입력: 50만 100만 300만 500만 │   │ ─────────────────────────────── │
└──────────────────────────────────┘   │ 같은 금액 8.8% 라면: 912,000원   │
                                       │ ⓘ 5월 종합소득세 신고 안내       │
                                       └──────────────────────────────────┘
```

- 탭은 기존 통합 페이지와 같은 `?mode=business` · `?mode=other` 쿼리로 전환한다 (URL 플랫 유지).
- 결과에 **다른 소득 구분으로 받았을 때의 실수령액 비교**를 한 줄 넣는다.
  "3.3% 와 8.8% 중 무엇이 유리한가"는 실제로 자주 나오는 질문이다.
  단, 소득 구분은 선택이 아니라 소득의 성격(계속·반복 여부)으로 정해진다는 점을 함께 적는다.
- 금액 입력은 천 단위 구분 표시, 한글 금액 보조 표기(예: 100만 원)를 붙인다.

### v1 범위 밖 (v2 후보)

- 여러 건 합산 (연간 지급 내역 → 기납부세액 합계)

## 6. 테스트 항목

- 사업소득: 1,000,000 → 소득세 30,000 · 지방 3,000 · 실수령 967,000
- 기타소득: 1,000,000 → 기타소득금액 400,000 · 소득세 80,000 · 지방 8,000 · 실수령 912,000
- 절사: 지방소득세가 절사된 소득세 기준으로 계산되는지 (3,102,370 사례)
- 소액부징수: 사업소득은 1,000원 미만도 징수 · 기타소득은 경계 처리
- 기타소득 과세최저한 경계: 지급액 125,000 / 125,010
- 역산: 결과 지급액의 forward 실수령액 ≥ 목표, 그리고 지급액 − 10 의 실수령액 < 목표 (최소성)
- 역산 무작위 검사: 1만~1억 범위 표본에서 위 두 조건 유지
- 정책 상수와 기간 경계 검사
