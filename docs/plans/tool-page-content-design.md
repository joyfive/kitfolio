# Kitfolio 개별 도구 페이지 콘텐츠 설계

대표 화면은 PDF 편집이다. 네 가지 조작 모드와 결과 형태가 달라 공통 가이드 구조를 시험하기 좋다. 이후 계산형(연봉 실수령액), 편집형(JSON 포매터), 나머지 도구에 적용한다.

참고한 [채널톡 알림톡 가이드](https://docs.channel.io/help/ko/articles/%EC%95%8C%EB%A6%BC%ED%86%A1-9747de9a)는 사전 조건과 조작 순서를 나누고, 각 단계에서 필요한 화면과 예외를 가까이 보여준다. Kitfolio에서는 실제 도구가 콘텐츠와 같은 URL에 있으므로 상단 작업 영역과 도움말 사이를 바로 오갈 수 있게 구성한다.

| 순서 | 영역 | 독자가 얻는 것 | 화면 구성 |
| --- | --- | --- | --- |
| 1 | 도구 | 입력, 계산·편집, 결과 복사나 저장 | 제목 한 줄과 짧은 결과 약속 뒤에 실제 도구. 작업 전의 필수 조건은 해당 입력 옆. |
| 2 | 사용 가이드 | 내 상황에서 어디를 눌러 어떤 결과를 받을지 | 실제 레이블로 2~4단계, 대표 입력 → 결과 예시, 해당 도구로 돌아가는 링크. 모드형 도구는 현재 모드에 맞춰 안내. |
| 3 | FAQ | 오류·제한·예외를 해결하는 방법 | 닫힌 질문 목록. 버튼, 오류 안내, 가이드에서 이미 답한 질문은 합치고 나머지는 질문별 앵커로 연결. |
| 4 | 배경 설명 | 원리, 비교, 한계, 결과 해석과 판단 기준 | 65~75자 내외의 산문 폭. 해당 페이지에서 꼭 필요한 내용을 먼저 보여주고 상세 글이 실제로 있으면 연결. |

PC는 도구를 전체 폭으로 두고, 아래부터 왼쪽에 앵커 목차·오른쪽에 본문을 둔다. 모바일은 도구 직후 한 줄 목차와 본문을 쌓고, 긴 제목은 줄바꿈한다. 페이지 영역을 탭으로 숨기지 않고 앵커로 접근한다. 기존 도구의 편집 모드 탭은 유지한다. ‘예시로 보기’는 가짜 값을 쓰는 체험을 의미하며 실제로 데이터를 입력하는 것과 명확히 구분한다.

## 기존 FAQ 이전 기준

- ‘무엇인가요’, ‘누구에게 필요한가요’는 제목 아래 문장과 가이드의 실제 상황으로 이동한다.
- ‘어떻게 쓰나요’는 조작 단계로 옮긴다. ‘왜 쓰나요’는 비교나 해석에 도움이 될 때 배경 설명에 남긴다.
- 암호 파일, 탭 전환 시 입력 유지, 반올림 차이처럼 실제 결정이나 복구에 필요한 질문은 FAQ에 남긴다.
- 데이터의 정확성, 보안, 적용 연도처럼 결과를 해석하는 데 필요한 정보는 결과 가까이에도 유지한다. FAQ 구조화 데이터에는 페이지에서 공개하는 질문과 답만 들어간다.

## 구현 순서

1. PDF에서 병합·분할·회전·페이지 삭제 가이드와 4개 영역을 먼저 적용한다.
2. 연봉 및 JSON에서 입력 → 결과 예시와 계산·편집형의 차이를 검증한다.
3. 현재 공개된 35개 도구의 한국어·영어 70개 페이지를 이 구조로 옮긴다. 이미 있는 사용 순서·실전 예시·제약·근거를 활용해 겹치는 문장을 걷어내고, 도구별로 첫 행동과 확인할 결과를 구체화한다.
4. 각 언어·도구의 실제 UI 레이블, 모드, 단계, 결과 형식, 도움말 앵커, 웹 화면의 FAQ와 구조화 데이터 일치를 확인한다. 320/390px 및 PC에서 입력 영역과 목차, FAQ 키보드 조작을 검증한다.

## 적용 및 검증 결과

- 공개 도구 35종의 국문·영문 70개 URL을 공통 구조로 연결했다. 각 가이드는 실제 사용 상황, 조작 순서 2~4개, 입력과 결과가 있는 대표 예시를 보여준다. 나머지 예시는 ‘다른 실전 예시’에서 펼친다.
- 배경 설명에는 기존 상세 문단, 제한 사항, 확인일과 공식 출처를 해당하는 도구에 유지했다. 관련 블로그 글이 있는 도구에는 본문에서 글을 열 수 있다.
- 기존 소개용 FAQ 탭을 제거했다. 구체적인 작업 질문은 브라우저의 기본 접기/펼치기를 사용하고, 화면의 질문·답변 순서와 FAQPage 데이터가 일치하도록 했다.
- PDF 4개 모드의 사용 순서와 결과는 별도로 작성했다. 연봉, JSON, 성장률, CAGR, 단위 변환, 광고 지표, QR 리더 등은 현재 선택한 모드나 방향에 맞춰 대표 예시나 단계를 바꾼다.
- 프로덕션 빌드로 모든 URL의 HTTP 응답, 도구 → 가이드 → FAQ → 배경 설명 순서, 목차 앵커, 예시 입력과 출력, FAQ 화면·구조화 데이터 일치, 320·390·1440px의 가로 넘침 여부를 확인했다.
- PDF·연봉·JSON은 국문과 영문에서 키보드로 도구 ↔ 가이드 이동과 FAQ 펼침을 검증했다. 한·영 PDF 모드, 연봉 입력 단위, JSON 압축, CSS 단위·성장률·광고 지표와 QR 읽기의 주요 모드도 브라우저에서 확인했다.
- 타입 검사와 기존 테스트 618개, 색인 대상 콘텐츠 검증, 정적 페이지 188개 생성이 통과했다.
