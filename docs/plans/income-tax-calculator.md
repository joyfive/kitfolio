## 0. 보류를 푸는 조건 (스코프 재정의)

로드맵은 이 도구를 두 가지 이유로 보류했다.

1. 공제 항목이 많아 정확도 위험이 크고 하루 안에 구현하기 어렵다.
2. 홈택스 모의계산과 경쟁해야 한다.

이 기획은 **"모든 사람의 종합소득세"를 계산하지 않는다.** 대상을 하나로 좁힌다.

> **3.3% 를 떼이고 일한 인적용역 프리랜서가, 5월 신고 전에 환급인지 추가 납부인지,
> 그리고 경비 처리 방식(단순경비율 · 기준경비율 · 간편장부) 중 무엇이 유리한지 확인하는 도구.**

- 정확도 위험: 소득 종류를 **사업소득(인적용역) 하나**로, 공제를 **인적공제 · 국민연금 · 표준세액공제**로
  제한하면 산식이 닫힌다. 범위 밖 입력은 계산하지 않고 "범위 밖" 안내로 돌린다.
- 홈택스와의 차별: 홈택스 모의계산은 로그인과 전체 항목 입력을 요구하고, 방식별 결과를 나란히 보여주지 않는다.
  이 도구는 **입력 4~5개 · 30초 · 방식 3개 비교 · 환급/추가 납부 한 줄**이 핵심이다.
- 하루 구현: 세율표는 `app/lib/salary/tax.ts` 에 이미 있고, 3.3% 원천징수 규칙은
  `app/lib/freelancer/` 에 있다. 새로 만드는 것은 경비율 테이블 · 추계 규칙 · 비교 화면이다.
- 수요 확인 경로: 1번 도구(프리랜서 3.3% 계산기)의 "5월 종합소득세 신고" 가이드·FAQ 가 이미
  "이 계산기는 지급 시점까지만 계산한다"고 끊는다. 이 도구가 그 다음 질문을 받는다.

**타이밍.** 오늘(2026-10-20) 착수하면 2026년 귀속 신고(2027년 5월) 전까지 약 6개월 동안
색인·노출을 쌓을 수 있다. 검색 수요는 4~5월에 몰리므로 **3월 경비율 고시 직후 갱신 → 4월 승격**을 목표로 한다.

## 1. 한 줄 정의

**종합소득세 계산기는 3.3% 원천징수를 받은 프리랜서의 연간 수입금액으로 단순경비율 · 기준경비율 ·
간편장부 방식별 종합소득세를 계산하고, 이미 떼인 세금과 비교해 5월 신고 때 환급받을 금액 또는
추가로 낼 금액을 보여주는 도구다.**

## 3. 산식

> ⚠️ 이 장의 조문 번호와 금액은 **기억에 기반한 초안**이다. 9장 체크리스트로 원문 대조를 끝낸 뒤
> 3.6 대조표를 ✅ 로 채운다 (프리랜서 기획서 3.3 과 같은 방식).

### 3.1 전체 흐름

```
수입금액 (연간 총 지급액, 3.3% 떼기 전)
 − 필요경비 (방식별: 3.2)
 = 사업소득금액                         → 음수면 0 (결손금 이월은 범위 밖)
 − 종합소득공제 (인적공제 + 국민연금 보험료)
 = 과세표준                             → 1원 미만 버림 (국고금 관리법 제47조 제2항)
 × 기본세율 (누진공제)
 = 산출세액
 − 세액공제 (표준세액공제 7만원 · 기장세액공제는 v1 범위 밖)
 + 가산세 (무기장가산세: 3.3)
 = 결정세액 (소득세)
 − 기납부세액 (원천징수된 3%)
 = 납부할 세액 (+) 또는 환급세액 (−)    → 10원 미만 절사

개인지방소득세 = 결정세액 × 10% − 원천징수된 지방소득세(0.3%)   (별도 표시, 합계도 함께)
```

### 3.2 필요경비 방식 3가지

| 방식 | 사업소득금액 | 쓸 수 있는 사람 |
|---|---|---|
| 단순경비율 (추계) | 수입금액 − 수입금액 × 단순경비율 | 직전연도 수입금액이 단순경비율 기준 미만인 계속사업자, 또는 해당연도 수입이 기준 미만인 신규사업자 |
| 기준경비율 (추계) | min( 수입금액 − 주요경비 − 수입금액 × 기준경비율 , 단순경비율 소득금액 × 배율 ) | 단순경비율 대상이 아닌 간편장부대상자 |
| 간편장부 (기장) | 수입금액 − 실제 필요경비 | 누구나 (장부를 쓴 경우) |

- 단순경비율은 **수입금액 4,000만원 초과분에 낮은 율(자가율)** 을 적용하는 규칙이 있다 (대조 필요).
- 기준경비율의 **주요경비**는 매입비용 · 임차료 · 인건비 중 증빙이 있는 금액만이다.
  인적용역 프리랜서는 대부분 0 에 가깝고, 그래서 기준경비율 대상이 되면 세금이 크게 오른다.
  **이 "단순 → 기준 전환 절벽"이 이 도구가 보여줘야 할 핵심 정보다.**
- 배율(간편장부대상자 · 복식부기의무자별)은 시행령 개정으로 바뀐 이력이 있어 **귀속연도 테이블**로 둔다.

### 3.3 대상 판정 (차별화 핵심 1)

입력: 귀속연도 · 업종코드 · 올해 수입금액 · 직전연도 수입금액 (또는 "올해 처음 시작")

```
신규사업자  : 올해 수입 < 복식부기 기준        → 단순경비율 가능
계속사업자  : 직전연도 수입 < 단순경비율 기준   → 단순경비율 가능
              직전연도 수입 < 복식부기 기준     → 기준경비율 (간편장부대상자)
              그 이상                           → 복식부기의무자: v1 범위 밖 안내
```

| 기준 (인적용역 940xxx) | 금액 | 근거 (대조 필요) |
|---|---|---|
| 단순경비율 적용 기준 | 3,600만원 (인적용역 특례로 알려짐. 일반 서비스업은 2,400만원) | 소득세법 시행령 제143조 제4항·제7항 |
| 간편장부대상자 (복식부기 기준) | 7,500만원 | 소득세법 시행령 제208조 제5항 |
| 무기장가산세 제외 소규모사업자 | 직전연도 수입 4,800만원 미만 또는 신규 | 소득세법 제81조의5 · 시행령 제147조의2 |

- **결과 화면은 "이 조건이면 쓸 수 있는 방식"에 배지를 단다.** 쓸 수 없는 방식도 숫자는 보여주되
  흐리게 처리하고 이유를 한 줄로 적는다 ("직전연도 수입 4,200만원으로 단순경비율 기준 3,600만원 이상").
- 직전연도 수입을 모르면 "올해와 같다고 가정"을 기본값으로 둔다.

### 3.4 무기장가산세

```
무기장가산세 = max( 산출세액 × (무기장 소득금액 ÷ 종합소득금액) × 20% , 수입금액 × 7/10,000 )
```

- 추계(단순·기준경비율)로 신고하면 장부를 쓰지 않은 것이므로 적용된다.
- **소규모사업자(신규 · 직전연도 수입 4,800만원 미만)는 제외.** v1 단일 소득 구조에서는
  비율이 1 이라 `max(산출세액 × 20%, 수입금액 × 0.07%)` 로 단순해진다.
  수입금액 기준 하한 때문에 산출세액이 0원이어도 가산세가 생길 수 있다 (구현 중 확인).
- 근거: 소득세법 제81조의5 (대조 필요).

### 3.7 검산 예시 (구조 확인용 · 경비율은 가정값)

940909(기타자영업) · 신규 아님 · 직전연도 수입 2,800만원 · 올해 수입 3,000만원 ·
본인만 · 국민연금 0 · 단순경비율 64.1% (2024년 귀속 고시, 2차 확인). 엔진 결과와 일치 ✅

```
필요경비      = 30,000,000 × 64.1% = 19,230,000
사업소득금액  = 10,770,000
과세표준      = 10,770,000 − 1,500,000 = 9,270,000
산출세액      = 9,270,000 × 6% = 556,200
결정세액      = 556,200 − 70,000 = 486,200          (소규모사업자라 무기장가산세 없음)
기납부세액    = 30,000,000 × 3% = 900,000
환급세액      = 486,200 − 900,000 = −413,800         → 413,800원 환급
지방소득세    = 48,620 − 90,000 = −41,380            → 41,380원 환급
합계 환급     = 455,180원
```

같은 사람이 직전연도 수입 4,000만원이었다면 기준경비율 대상이 되어 결과가 크게 달라진다.
이 대비를 예제(`content.examples`) 하나로 쓴다.

## 4. 화면 구성 (Layout A · Card)


- **탭(`?mode=`) 없이 한 화면에서 3개 방식을 나란히** 보여준다. "어느 방식이 유리한가"가 이 도구의 답이다.
- 기납부세액은 기본값 `수입금액 × 3%` 로 자동 채우고 직접 수정할 수 있게 한다
  (원천징수를 안 한 거래가 섞인 경우).
- 고급 입력을 열지 않으면 간편장부 방식은 "실제 경비를 넣으면 계산" 상태로 둔다.
- 결과 하단 경고 배지: 단순경비율 기준 근접 (직전연도 수입이 기준의 90% 이상) ·
  복식부기 기준 초과 (범위 밖) · 결정세액 0 (전액 환급).
- 금액 입력은 천 단위 구분 + 한글 금액 보조 표기 (프리랜서 계산기 입력 컴포넌트 재사용).

### 역산 (차별화 핵심 2, v1 포함 여부는 8장 결정 4)

"환급을 0 으로 맞추려면 실제 경비가 얼마 필요한가" · "이 방식이 단순경비율보다 유리해지는 실제 경비"
를 이분 탐색으로 구한다. 간편장부를 쓸지 판단하는 데 직접 쓰이는 숫자다.

  고시가 나오지 않은 연도(예: 2026년 귀속을 2026-10 에 선택)는 직전 고시를 쓰고
  "2026년 귀속 경비율은 2027년 3월 고시 예정: 2025년 귀속 경비율로 추정" 을 표시한다.
- 업종 목록은 v1 에서 인적용역 940xxx 중 검색 수요가 있는 6~8개로 제한한다
  (예: 940100 저술가 · 940200 화가 관련 · 940500 영화·연극 관련 · 940903 학원강사 · 940909 기타자영업 ·
  940926 소프트웨어 프리랜서 · 940906 보험설계사. 코드·명칭은 고시 대조).

## 6. 테스트 항목

- 기본세율: 각 구간 경계(1,400만 · 5,000만 · 8,800만 · 1.5억 …)에서 누진공제 방식과 구간별 누적 방식 결과 일치
- `salary` 기존 테스트 전체 통과 (세율표 추출 회귀)
- 단순경비율: 4,000만원 초과분 낮은 율 적용 경계 (40,000,000 / 40,000,001)
- 기준경비율: 배율 상한이 걸리는 경우와 안 걸리는 경우 각각
- 대상 판정: 직전연도 수입 기준 경계 (3,599만 / 3,600만 · 7,499만 / 7,500만) · 신규사업자 분기
- 무기장가산세: 직전연도 4,800만원 경계 · 신규 제외 · 간편장부 방식에는 미적용
- 사업소득금액 음수 → 0 · 과세표준 음수 → 0 · 결정세액 음수 → 0
- 끝수: 과세표준 1원 미만 버림 · 납부/환급세액 10원 미만 절사
- 지방소득세: 결정세액 × 10% − 원천징수 지방소득세, 소득세와 독립 계산
- 기납부세액 기본값 = `WITHHOLDING_POLICY` 기준 3% 와 일치
- 경비율 테이블: 모든 업종 × 귀속연도에 필수 필드 존재 · 고시 미발표 연도 fallback 표시 플래그
- 역산(포함 시): 결과 경비의 forward 결정세액이 목표 이하 · 경비 − 1원은 목표 초과 (최소성)
