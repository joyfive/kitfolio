# Tool Selection

Score every new tool idea on a 25-point scale. Prioritize the highest totals.

| Criterion              | Max |
| ---------------------- | --- |
| Real usefulness        | 5   |
| Search demand          | 5   |
| Implementation ease    | 5   |
| Runs fully in-browser  | 5   |
| KitFolio brand fit     | 5   |

**Total: 25**

## How to use
- Any criterion scoring very low (especially "runs fully in-browser") is a likely disqualifier, not just a low total.
- Use this together with the `/new-tool` skill checklist (which is a hard gate: all five questions must be "yes").
- Tie-break by search demand, then implementation ease.

## Priority heuristic
search volume > low implementation difficulty > poor UX of existing tools
