# Kitfolio 업무 프롬프트 · 작성 가이드

`/prompts` 는 일할 때 바로 붙여 쓰는 프롬프트를 제공하는 섹션이다. 계산기처럼 "일할 때 꺼내 쓰는 도구"의 한 종류다.

- **AI 생성 기능은 없다.** 운영자가 직접 쓰고, 커밋·배포하면 게시된다 (CMS·DB 없음).
- **발행 주기:** 비정기, 주 1~4회 목표.
- **추천인·제휴 링크를 넣지 않는다.**

## 파일 규칙

```
content/prompts/<slug>.ko.md   # 한국어
content/prompts/<slug>.en.md   # 영어 (선택)
```

- URL: `/prompts/<slug>` (KO), `/en/prompts/<slug>` (EN).
- slug 은 소문자·숫자·하이픈만.
- 한쪽 언어만 있어도 된다. 있는 언어에만 페이지·목록·sitemap 이 생기고, 두 언어가 다 있으면 hreflang 으로 연결된다.
- `_` 로 시작하는 파일은 읽지 않는다. `_template.ko.md` 를 복사해서 시작한다.

## 프론트매터

```yaml
---
title: 퇴근이 빨라지는 초간단 프롬프트     # 필수 · 목록 썸네일과 공유 이미지에도 이 문구가 들어간다
description: 검색 결과·목록에 쓰이는 한두 문장 요약   # 필수
date: 2026-12-18          # 필수 · 게재일 (목록 정렬 기준, 화면에 "게재"로 표시)
updated: 2026-12-20       # 선택 · 내용 수정일 (화면에 "업데이트"로 표시)
tags: 답변 형식, 클로드     # 선택 · 쉼표 구분
relatedTools: character-counter   # 선택 · 관련 도구 slug, 쉼표 구분
draft: true               # 선택 · 프로덕션에서 제외, 개발 서버(npm run dev)에서만 보임
---
```

## 썸네일

대표 이미지를 만들지 않는다. **제목으로 자동 생성된다.**

- 목록 카드: 제목 텍스트를 그린 썸네일 (이미지 파일 없음)
- 공유 이미지(OG): `/prompts/<slug>/opengraph-image` 가 빌드 때 제목으로 1200×630 PNG 를 만든다

제목이 곧 썸네일이므로 **짧고 구체적으로** 쓴다. 세 줄을 넘으면 목록 썸네일에서 잘린다.

## 프롬프트 본문은 코드 블록에

그대로 붙여 넣을 문장은 코드 블록(```)에 쓴다. 상세 페이지에서 코드 블록마다 **복사 버튼**이 붙는다.

## 메뉴 경로는 토큰으로

"설정 › 당신의 Claude › 지침"처럼 다른 서비스의 메뉴 경로는 본문에 직접 쓰지 않는다.
`app/lib/ui-paths.ts` 에 한 번만 적고, 본문에서는 토큰으로 쓴다.

```md
{{ui:claude-instructions}} 칸에 붙여 넣으세요.
```

- 렌더할 때 글의 언어에 맞는 경로로 바뀐다.
- 없는 id 를 쓰거나, 그 언어 경로가 비어 있으면 빌드와 `npm test` 가 실패한다.
- 글 하단에 "이 글의 메뉴 경로는 YYYY-MM-DD에 확인한 화면 기준" 안내가 자동으로 붙는다 (글이 쓴 경로 중 가장 오래된 확인일).
- 서비스 화면이 바뀌면 `ui-paths.ts` 의 해당 항목과 `verifiedAt` 만 고친다. 그 경로를 쓰는 모든 글에 반영된다.
- 새 경로가 필요하면 `ui-paths.ts` 에 항목을 추가한다. `verifiedAt` 은 실제 화면에서 확인한 날짜만 쓴다.

## 고유성

다른 곳에도 있는 프롬프트를 옮겨 적는 것만으로는 이 페이지만의 가치가 생기지 않는다. 가능하면 아래 중 하나 이상을 넣는다.

- 같은 질문에 대해 적용 전과 적용 후 답변 비교 (직접 돌려 본 결과)
- 잘 안 맞았던 경우와 고친 방법
- 내 업무 상황에 맞춘 변형

원출처가 있으면 본문 끝에 밝힌다.
