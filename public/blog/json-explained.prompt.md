# Kitfolio Blog Cover Image Prompt

## Series identity

- **Brand:** Kitfolio
- **Use:** Editorial blog cover
- **Format:** 16:9, 1200×675
- **Visual language:** Clean SaaS, semi-flat vector infographic
- **Background:** Very light blue-gray, primarily `#F2F5FF`
- **Primary colors:** `#2D5DC8`, `#6486EF`
- **Supporting colors:** `#D4D9E5`, `#61646F`
- **Optional highlight:** A tiny amount of muted amber, under 5% of the image
- **Composition:** Low-to-medium density, centered visual balance, 15–20% outer negative space
- **Shape language:** Soft rounded rectangles, circles, thin connector lines, subtle nodes
- **Rendering:** Flat or semi-flat, front-facing orthographic view, minimal soft shadow
- **Consistency rule:** Use the same palette, line weight, corner treatment, background tone, and object density across the full nine-image series

## Article

**JSON이란 무엇인가 | 비개발자도 이해하는 데이터 형식**

## Core visual idea

JSON을 코드 화면으로 보여주는 대신, **객체와 배열이 계층적으로 중첩되고 포맷팅·검증을 통해 정돈되는 데이터 구조**로 표현합니다.

## Composition

- Center: two large abstract curly braces framing a nested data structure
- Inside: stacked key-value-like rows represented only by paired dots and bars
- Include one nested rounded card and one short array-like sequence of repeated nodes
- A thin validation path should lead to a subtle check-shaped geometric mark
- Indentation and hierarchy should be immediately visible
- No actual keys, values, punctuation strings, or code text

## Final generation prompt

```text
Kitfolio editorial blog cover, 16:9.

Create a clean semi-flat vector infographic representing JSON as a structured, human-readable data format. Use two large abstract curly brace shapes to frame a clearly nested hierarchy. Inside, arrange paired dots and short bars like key-value rows, include one nested rounded object card, and add one compact sequence of repeated nodes suggesting an array. Show indentation and hierarchy through alignment and spacing. Add a subtle validation path ending in a small geometric check mark, suggesting formatting and syntax validation. The result should feel like organized data rather than a code screenshot.

Use a very light blue-gray background (#F2F5FF), cool blue accents (#2D5DC8 and #6486EF), and neutral blue-gray support tones (#D4D9E5 and #61646F). Use restrained geometric forms, consistent thin outlines, soft rounded corners, subtle diagram nodes, minimal soft shadows, and generous negative space. Front-facing orthographic composition, calm professional modern SaaS mood, low-to-medium visual density, centered and balanced.

No readable text, no letters, no numbers, no code snippets, no fake keys or values, no terminal window, no people, no photorealism, no 3D render, no hand-drawn texture, no neon colors, no dark background, no decorative clutter.
```

## Avoid

- A literal code editor
- Random braces with no hierarchy
- Fake JSON text
- Terminal aesthetics
- Cybersecurity or hacker imagery
