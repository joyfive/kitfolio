# Kitfolio Blog Cover Image Prompt

## Series identity

- **Brand:** Kitfolio
- **Use:** Editorial blog cover
- **Format:** 16:9, 1200×675
- **Visual language:** Clean SaaS, semi-flat vector infographic
- **Background:** Very light blue-gray, primarily `#F2F5FF`
- **Primary colors:** `#2D5DC8`, `#6486EF`
- **Supporting colors:** `#D4D9E5`, `#61646F`
- **Optional highlight:** A tiny amount of muted amber, under 5% of the image
- **Composition:** Low-to-medium density, centered visual balance, 15–20% outer negative space
- **Shape language:** Soft rounded rectangles, circles, thin connector lines, subtle nodes
- **Rendering:** Flat or semi-flat, front-facing orthographic view, minimal soft shadow
- **Consistency rule:** Use the same palette, line weight, corner treatment, background tone, and object density across the full nine-image series

## Article

**SNS·자기소개서 글자 수 | 플랫폼별 제한과 정확히 세는 법**

## Core visual idea

추상적인 텍스트 블록이 **정해진 제한 범위 안에서 실시간으로 채워지는 상태**를 보여줍니다. 실제 글자나 숫자는 사용하지 않고, 길이가 다른 선과 게이지로만 표현합니다.

## Composition

- Center: one clean document or editor card
- Inside: several abstract horizontal text lines of different lengths
- Right or lower edge: a circular progress gauge or segmented limit ring
- A subtle boundary marker indicates the maximum length
- A few small overflow dots approach the boundary but do not cross it
- Keep the layout calm and precise, closer to an editorial utility than a social media illustration

## Final generation prompt

```text
Kitfolio editorial blog cover, 16:9.

Create a clean semi-flat vector infographic about measuring writing length against a fixed character limit. Place one minimal document or editor card in the center with several abstract horizontal text lines of different lengths. Add a circular progress gauge or segmented limit ring beside the card, with a clear but unlabeled maximum boundary. Show a few small content blocks filling the available range in a controlled way, suggesting real-time counting and remaining capacity. The visual should feel precise, calm, private, and useful for social posts, applications, and scripts without depicting any specific platform.

Use a very light blue-gray background (#F2F5FF), cool blue accents (#2D5DC8 and #6486EF), and neutral blue-gray support tones (#D4D9E5 and #61646F). Use restrained geometric forms, consistent thin outlines, soft rounded corners, subtle diagram nodes, minimal soft shadows, and generous negative space. Front-facing orthographic composition, calm professional modern SaaS mood, low-to-medium visual density, centered and balanced.

No readable text, no letters, no numbers, no words, no platform logos, no social media logos, no people, no keyboard, no photorealism, no 3D render, no hand-drawn texture, no neon colors, no dark background, no decorative clutter.
```

## Avoid

- Fake AI-generated text
- Platform logos
- A literal stopwatch as the main object
- A dense word cloud
- Multiple unrelated document cards
