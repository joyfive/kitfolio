# Product Direction Review

When reviewing KitFolio (a feature, a tool, a scope decision), evaluate:

- Is this aligned with "Small tools for modern knowledge workers"?
- Does this simplify work?
- Does it reduce repetitive tasks?
- Is the UX focused?
- Is the feature scope minimal?

## Decision rules
- **Reject feature creep.** Prefer shipping small, focused tools over building large applications.
- One tool = one clear problem.
- Browser-first, no login, no installation, client-side processing.
- The tool is the product; text exists only to improve discoverability (SEO/AEO).

If a proposal fails these tests, recommend scoping it down or splitting it into a separate focused tool rather than expanding an existing one.
