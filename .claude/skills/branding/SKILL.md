# Branding Skill

KitFolio brand positioning:

> **Small tools for modern knowledge workers.**

When making branding decisions:

**Prioritize**
- Simplicity
- Professionalism
- Trust
- Practicality

**Avoid**
- Excessive illustrations
- Playful startup aesthetics
- Trend-driven design
- Developer-only messaging

Every branding decision should reinforce:
- speed
- usefulness
- clarity
- professionalism

The homepage should communicate one thing above all:
> "Find a useful tool quickly."

## Consistency notes
- Visual identity follows the design tokens and three-layout system defined in the root `CLAUDE.md` (Card / IDE / Canvas). Do not invent new aesthetics that conflict with those tokens.
- Tone: concise, factual, professional. No hype, no emoji-driven marketing copy.
