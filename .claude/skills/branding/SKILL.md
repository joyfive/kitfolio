# Branding Skill

KitFolio brand positioning (2026-10-24):

| | |
|---|---|
| Product | 계산·변환·생성·점검에 필요한 작은 웹 도구 모음 · Small web tools to calculate, convert, create and check |
| Core user | Anyone who wants a result now, without installing software or starting a complicated workflow |
| Value | Easy to find · short to use · result usable right away |
| Message | **필요한 도구를 찾아, 하던 일을 계속하세요.** / **Find the tool. Get back to work.** |

The audience is **not** defined as a list of job titles. PM, designer, office worker etc. appear only as use cases inside a tool's `aeo.who` and FAQ, never as site-wide targeting or hub filters.

When making branding decisions:

**Prioritize**
- Simplicity
- Professionalism
- Trust
- Practicality

**Avoid**
- Excessive illustrations
- Playful startup aesthetics
- Trend-driven design
- Developer-only messaging
- Job-title targeting in site-level copy ("for PMs and designers") or knowledge-worker jargon

Every branding decision should reinforce:
- speed
- usefulness
- clarity
- professionalism

The homepage should communicate one thing above all:
> "Find a useful tool quickly." Discovery is by topic (8 categories) then task (7 action tags), plus search by the job ("PDF 합치기").

## Consistency notes
- Visual identity follows the design tokens and three-layout system defined in the root `CLAUDE.md` (Card / IDE / Canvas). Do not invent new aesthetics that conflict with those tokens. Layout names (Clean, IDE, Canvas) are internal; never show them to users as tags.
- Tool names: the page language's name is the main title, the other language is secondary (KO: 국문 메인 / EN: English main), on cards and in the h1 alike.
- Tone: concise, factual, professional. No hype, no emoji-driven marketing copy.
